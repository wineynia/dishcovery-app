# Dishcovery

A recipe browser built with **Next.js (App Router), React, TypeScript and TailwindCSS**. Recipes come from [TheMealDB](https://www.themealdb.com/api.php), which is free and needs no API key.

## Requirements

- Node.js 18.18 or newer (Node 20 or 22 recommended)
- npm
- An internet connection, since recipe data comes from TheMealDB

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
